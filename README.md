### 🤖 AI Resume Analyzer &nbsp;`Java · Spring Boot · React · Apache Tika`
> Full-stack resume analysis platform with a **100% Java NLP engine** — no OpenAI, no external AI APIs, everything runs locally.
> - **500+ skill dictionary** with word-boundary matching for accurate skill extraction
> - **9-dimension ATS scorer** (contact info, formatting, action verbs, experience quality, etc.)
> - **TF-IDF + Cosine Similarity** job matching implemented from scratch in pure Java
> - Rule-based suggestion engine generates TIP / WARN / GAP improvement tips
> - React frontend with drag-and-drop upload, animated results dashboard, dark theme

### 🌦️ Weather Forecast & Monitoring AI &nbsp;`Python · Flask · CatBoost · Node.js · React · MongoDB`
> Real-time weather monitoring platform with a **3-service ML architecture** — React frontend, Express backend, and a Python/Flask AI engine.
> - **CatBoost ML model** trained on historical datasets for rainfall probability prediction
> - **Pattern detection** for severe weather: rapid pressure drops, high winds, UV spikes
> - **Emotion-based dynamic UI** — themes, colors & animations shift based on live conditions (Sunny, Rainy, Stormy…)
> - Smart alert dashboard for extreme weather warnings in real time

[![Repo](https://img.shields.io/badge/View_Repo-WeatherAI-58a6ff?style=flat-square&logo=github)](https://github.com/rydhym/weather-forecast-and-monitoring-using-AI)

### 🔍 Deep Packet Inspection Engine &nbsp;`C++ · Python · CMake`
> Multi-threaded DPI engine with a **2-tier pipeline** (2 Load Balancer × 4 Fast Path threads) using thread-safe producer-consumer queues.
> - **5-tuple consistent hashing** — the same thread always owns the same connection
> - Parses raw **TLS Client Hello** byte-by-byte to extract SNI (YouTube, GitHub, etc.) — **without decrypting traffic**
> - Enforces domain / IP / app-level blocking rules at the network layer

[![Repo](https://img.shields.io/badge/View_Repo-Deep--Packet--Inspection-58a6ff?style=flat-square&logo=github)](https://github.com/rydhym/Deep-Packet-Inspection)

---

### ⚙️ CPU Scheduling Visualizer &nbsp;`C++ · Python · JavaScript`
> Full-stack simulator for **8 scheduling algorithms** (FCFS, RR, SPN, SRT, HRRN, FB-1, FB-2i, Aging) with **SMP support** for 1, 2, 4, or N cores.
> - C++ simulation engine → Python HTTP middleware → JS/HTML/CSS frontend
> - Renders **dynamic Gantt charts** with Turnaround Time, Waiting Time & NTT metrics
> - Validated with **Google Test Framework** across all algorithms and edge cases

[![Repo](https://img.shields.io/badge/View_Repo-OS--Project-58a6ff?style=flat-square&logo=github)](https://github.com/rydhym/operating-system-Project)
