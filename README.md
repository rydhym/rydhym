### 🔍 Deep Packet Inspection Engine
`C++` `Python` `CMake`

Multi-threaded DPI engine with a two-tier pipeline (load balancer + fast-path worker threads) and thread-safe producer-consumer queues. Uses 5-tuple consistent hashing so a connection is always handled by the same thread, and parses raw TLS Client Hello messages byte-by-byte to extract SNI — without decrypting traffic.
